# AGENTS.md: yavs-lower

Read the root `AGENTS.md` first. This file is for an agent about to change `crates/yavs-lower`.
The design, the module ownership table, the HIR to IR mapping table, the contract with
yavs-interp and yavs-elab and the Requests are in `crates/yavs-lower/DESIGN.md`; read it.

## 1. Purpose and boundaries

- Lowers yavs-sem's typed HIR to one `yavs_ir::Program`: one `Func` per process, subprogram body
  and elaboration body **per design unit** (shared by every instance, ir.md 2), plus a `UnitIr`
  per architecture (instance values, constants, signals, processes, driver slots) for the
  elaborator. Subprograms are lowered on first reference, so unused std/ieee bodies are not.
- Does not: own IR types (it only uses `yavs_ir::ProgramBuilder`/`FuncBuilder` and the
  verifier), analyze (input must be an error-free `Db`), fold generics or build the hierarchy
  (`yavs-elab`), or execute (`yavs-interp`).
- Depends on: `yavs-diag`, `yavs-ffi` (C type mapping), `yavs-syntax`, `yavs-sem`, `yavs-ir`, `yavs-kernel` (dev: `yavs-elab`,
  `yavs-interp`, `yavs-logic`). Called by: `yavs-elab` (`Elaborated::lower`).

## 3. Design decisions that bind this module

| Decision | Why | Source |
|---|---|---|
| `'path_name`/`'instance_name` of an item of a library-unit package (a package subprogram's parameters and locals included) lowers to a constant string (`pathname.rs`), not a slot in the instance data | The subprogram is lowered once and shared by every architecture; a slot belongs to the architecture lowered first, so a call from another architecture read garbage or failed with an internal error (#460) | #460 |
| An alias of a logic element or slice of a variable with a static name has no storage: uses lower the aliased name (reads and writes), seen with the alias subtype's bounds; a non-static name stays `E2001` | Logic arrays are bit planes, so the part is not addressable; a static name denotes the same part at every use (#296) | LRM 6.6.2 |
| A name below a record signal made of fields, nested fields and indexed elements (`r.f`, `r.sub.g`, `arr(i).f`, `arr(i)`) reads only the leaves it selects (`Fx::rec_part`, `comp_select`): one `SigRead` of the leaf, or `SigReadScalar` for a scalar leaf, never the whole record and then a field select; slices of an array of records still read all of it | A process naming one field of a 40-field control record copied the whole record on every activation, and the neorv32 processor testbench ran twice as long; the reference simulator keeps a record signal as one handle per field and selects by offset | #521 |
| A `Failed` that reaches a `Lowerer` entry point with no diagnostic is an ICE (`Cx::take_failed`), never an empty error list | A failed run must always say why (#292) | root `AGENTS.md` rule 1 |
| `Lowerer::capture_free_objects(vars)` (elaboration-time calls): constants and generics of entity, architecture, block and generate regions that a function reads become instance-data slots (`FreeObj`) for the caller to fill; a generic is captured even when its default folds to a literal, since the actual may differ. With `vars`, a shared variable of such a region is a slot holding its object's handle, or for a non-protected one (`--relaxed`) the address of its slot behind an instance cell (`FreeObj::var`, `Lowerer::region_var_init` is the thunk that creates the object); `free_for(f)` lists what `f` and its callees read. | An array variable with locally static bounds reads its descriptor from the constant pool (`Cx::const_dope`, `AddrOf Const`), not from the pointer in its frame slot; the slot still holds the pointer and a copy for debuggers and the collector | One `Load` less per `Pos`, and the optimiser can read the bounds (#427) | `func.rs` `var_init` |

| `new T'(array value)` and `new T(bounds)` with an all-zero default, and an array variable with such a default, allocate with `NewFill` (descriptor, then a copy or a repeated zero byte), never through a temporary copied by `New` | Large library storage arrays were written three times (#425, #427) | `composite.rs` `new_object`, `zero_default` |
| `s(i)` and `s(i)(a to b)` of an array-of-arrays signal, and `s(i)(j)`, read only the selected kernel range (`sig_steps`), never the whole signal | Reading all of a 512 by 16 signal per activation cost 60% of a run (#436) | `expr.rs` `sig_part`, `sig_elem` |
| One code per design unit; generics, signals and non-locally-static constants are instance data (`Space::Inst`), never folded into code | Shared code, rule 4 identity | ir.md 2, DESIGN.md "Shape" |
| A process with a sensitivity list that reads a record signal as a whole in two places or more keeps one copy of it (`SigCopies`, `Fx::whole_reads`, `Fx::sigcopy_of`): made in the declarative part, filled at the start of each activation, every whole read in the body is its address. | A record signal, or a part of one that is a record or an array of records (a field, an element `s(i)`, a slice at the end of the name), whose leaves are scalars or arrays of scalars below records and arrays of records, is read by one `SigGather` (`Fx::gather_part`, `read_obj`, the per-activation copy) and driven by one waveform element through its own drivers by one `SigScatter` (`Fx::scatter_table`, `drive_record`; the drive-deleting pass, `yavs-ir` `opt/drives.rs`, drops the scatter of a default where an override follows); the value's array lengths are checked first (`check_value_desc`); anything else (signal parameters, several waveform elements) keeps the drive and read per leaf. | Precise GC roots (#422): scalars of access and protected types live in `RegTy::Handle` registers (`Fx::rt_of`, used by `scalar`, `value_at` and call results); every slot that holds a handle or an address into the heap is a root (`local_access`, access parameters, method `self`, the object slot of `prot_new`: `Handle`; parameters passed by reference, array parameters, aliases: `Addr`); a temporary value whose type can hold handles is allocated with `Fx::alloc_val` or recorded with `Fx::temp_root` once its descriptor is filled, and a fat pair `[data, desc]` with `Fx::fat_root` once both words are stored | The heap is collected inside long activations from these roots only; nothing is scanned conservatively. A handle in a register of another type at a safepoint makes a `gc-stress` build of yavs panic (`crates/yavs-interp/AGENTS.md`) | `docs/decisions.md` "Shared heap collection", ir.md 1.4 |
| A call of a user function that is exactly the gate-fold idiom (`v := identity; for i in d'range loop v := v gate d(i); end loop; return v`, `and`/`or`/`xor` of `std_logic_1164`) is the native of the unary operator (`reduce.rs`), unless `no_native_ieee` or coverage | A loop of seven interpreter operations per bit became one word-parallel fold; neorv32 `counter_increment` 13.5 to 7.1 us (#531) | `docs/decisions.md` "Reduction idiom as a native" |
| A logic vector field of a record signal (through records only) is read by `SigRead` into the field of the value, not into a temporary and copied (`Fx::read_leaves`, `plain_vector_field`); leaves below arrays of records still go through a leaf buffer | Per leaf this dropped the buffer allocation, its size arithmetic and an `LCopy` | #519, test `composite/record_signal_vector_read` |
| A choice range of an aggregate of a one-dimensional array with at most four static elements (`AGG_UNROLL`, `(0 to 0 => cin)`) is written element by element (`Pos` and the store per element), not as a loop | A loop made the process a compute loop for `--tier=auto` (the full `O2` pipeline, 58 ms for a 135-instruction adder process) and kept the writes of the signal out of the `CopyDrive` fusion (#713) | `docs/decisions.md` "Carry-in aggregates and copies of the same module" |
| A slice of a signal of a plain array type (`s(h downto l)`, the prefix a signal name) is read as the sub-signal the slice selects (`Fx::sig_slice`, `sig_steps`), not as a read of the whole signal followed by an `LCopy` of the slice | The copy out of the whole read cost two operations and the bytes of the whole signal for every slice operand of an adder process, and for a slice of a wide bus the whole bus (#713) | `docs/decisions.md` "Carry-in aggregates and copies of the same module" |

Module-local decisions go in this section and DESIGN.md in the same commit (root `AGENTS.md`

## 4. Invariants and pitfalls

- Lowering a unit with errors is an ICE: callers must stop after sem errors.
- Every function goes through the yavs-ir verifier; a verifier error is an ICE of this crate,
  never "fixed" by relaxing the verifier.
- The calling and native conventions (fat pair `[data, dope]`, `ieee` natives' array values
  `data, left, right, dir` (`expr.rs` `Conv`; also the string target of the textio READ natives, #771), cells per parameter, signal
  parameter = two cells) are shared with `yavs-interp`: change both, note it in DESIGN.md and
  `crates/yavs-ir/README.md`.
- Kernel offsets of non-static indices must use the same rule as `yavs_elab::NetGraph::select`.
- `tests/corpus.rs` writes its library to a fixed `temp_dir()/yavs-lower-work`, which collides
  between worktrees and parallel runs (#160); until fixed, do not run two of them at once.
- A folded logic-array constant of arrays of unconstrained arrays (`Fx::encode`/`codes`) must carry the descriptor of every level, not only the first element level (#329).
- **`Cx`, `UnitIr`, `PackageIr` and what they hold are serialised (`Lowerer::image`, #407).** A new field of `Cx` derives `serde::Serialize`/`Deserialize` or is `#[serde(skip)]` because it is empty between lowerings (`diags`); a field that holds anything outside the `Db`'s ids and the IR (a reference, a pointer) cannot be added. The image is valid only for the `Db` it was made from, which the caller (`yavs-elab` `package_lowerer`) guarantees. `Lowerer::from_image` reads the program with `yavs_ir::lazy_bodies`: the lowerer reads the headers of functions it restored, never their code, and must keep doing so (#481). A subprogram lowered before any architecture is lowered gets the same code whatever architecture follows, except one that reads a `'path_name` or `'instance_name` (a cell of the architecture's instance data), one that uses an external name before it is bound, and the callers of those: `Lowerer::context_dependent` names them (`Cx::context_funcs` is filled where they are lowered, and by a failed lowering), `fingerprint`/`from_shared_image`/`funcs`/`shared_size`/`package_irs` serve the library stages (`docs/decisions.md` "Library stages"). Anything new that makes a subprogram's code depend on the architecture being lowered must add its function to `context_funcs`.
- A shared `CARGO_TARGET_DIR` can link another worktree's crates into the test binary (#7).

## 5. How to work here

```sh
CARGO_BUILD_JOBS=6 cargo test -p yavs-lower                     # unit tests and the corpus PASS list
cargo test -p yavs-lower --test corpus -- --nocapture           # print the non-passing files with their diff
python3 tools/difftest/difftest.py --candidate yavs             # full differential run (tools/difftest)
tools/difftest/report.sh                                        # rewrite tests/corpus/RESULTS.md
```

- A newly passing corpus file goes into `PASS` in `tests/corpus.rs` in the same commit; refresh
  `tests/corpus/RESULTS.md` with `tools/difftest/report.sh`.
- Codes owned: `E2000`-`E2099` (in use: `E2001` not lowered yet), plus `E9999`.
