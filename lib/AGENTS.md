# AGENTS.md: lib/ (std and ieee sources)

Read the root `AGENTS.md` first. This file is for an agent about to change anything under `lib/`.
`lib/README.md` (layout, licensing, tools, the reference simulator result), `lib/SOURCES.md` (origin, pinned commit,
every edit) and `lib/NATIVE.md` (native symbols) are the binding documents.

## 1. Purpose and boundaries

- The vendored IEEE VASG `std` and `ieee` package sources for 2008 and 2019
  (`std/{2008,2019}`, `ieee/{2008,2019}`) and the 1993 trees (`std/1993`, `ieee/1993`, #629), analyzed on demand by `yavs-sem` from source (no
  precompiled cache). A design is analyzed against one revision, the newest in its closure.
- `NATIVE.md`: every bodiless std subprogram and implicit-operation family yavs implements
  natively, with its native symbol (consumed by `yavs-sem` `mangle.rs`, `yavs-interp`, `yavs-ir`).
- `ORDER.md`: analysis order per revision (machine readable).
- The Synopsys packages are vendored unmodified in `ieee/*/std_logic_{arith,unsigned,signed,misc}*`
  (#117); their black-box testbenches are `tests/corpus/synopsys/`.
- Not here: external test runner, verification or vendor libraries (external corpora, fetched, never committed).

## 2. Map

| Path | What |
|---|---|
| `std/1993/` | `standard` and `textio` derived from the 2008 copy by deleting what 2008 added (`tools/derive_libs.py`); no `env` |
| `std/{2008,2019}/` | `standard`, `textio`, `env`; 2019 adds `reflection` (declarations only) |
| `ieee/1993/` | `std_logic_1164` (own `std_logic_vector` type), `std_logic_textio` (Synopsys), `math_real`, `math_complex`, Synopsys and VITAL packages vendored unmodified; `numeric_std`/`numeric_bit` derived from the 2008 files by `tools/derive_libs.py` (`numeric93()`); `tools/update-ieee-libs.sh` preserves the vendored ones and checks the derived ones |
| `ieee/{2008,2019}/` | `std_logic_1164`, `std_logic_textio`, `numeric_std[_unsigned]`, `numeric_bit[_unsigned]`, `math_real`, `math_complex`, fixed/float packages, the VITAL and Synopsys packages, two contexts; `-body` files |
| `NATIVE.md` | Generated by `tools/gen_native_md.py` from the std sources plus a static families part in the script |
| `ORDER.md` | Dependency order |
| `SOURCES.md` | Upstream commit, licence check, each edit made by `tools/derive_libs.py` |
| `UPSTREAM.sha256`, `SHA256SUMS` | Hashes of upstream files and of the vendored files |

## 3. Design decisions that bind this module

| Decision | Why | Source |
|---|---|---|
| Sources are byte-for-byte upstream except documented edits made by `tools/derive_libs.py`; never hand-edit | `SHA256SUMS` and `tools/update-ieee-libs.sh --check` must stay valid | `lib/SOURCES.md`, root `AGENTS.md` section 2 |
| `std` bodies are native (`yavs-std`, `yavs-interp`), named by `NATIVE.md` symbols | IEEE `std` has declarations only | `docs/plan.md` "Library sources", `docs/design/sem.md` 2.10 |
| Files are Latin-1; the 8-bit bytes in STANDARD and NUMERIC_* must survive | LRM 15.2 | `tools/derive_libs.py` |
| Old `rsim` comments in vendored files are kept | `SHA256SUMS` stays valid after the rename | `docs/decisions.md` "Project name" |
| One `std`/`ieee` revision per design; mapping `std`/`ieee` as user libraries is an error | Same `INTEGER` everywhere (user, 2026-10-18) | `docs/plan.md` "Test-runner integration", `docs/cli-contract.md` 3 |
| `ieee/*/std_logic_{arith,unsigned,signed,misc}*` (Synopsys) are the original files, byte for byte, always visible in `ieee`; `arith`/`unsigned`/`signed` are cut at the line between package and body so the loader finds `-body.vhdl`; licence note `LICENSE-SYNOPSYS`; `tools/update-ieee-libs.sh` preserves them. Never write or edit their text | User decision 2026-10-19 (#117), supersedes the clean-room plan | `lib/SOURCES.md` "Synopsys packages" |
| `ieee/*/vital_*` (IEEE 1076.4 VITAL 2000) are vendored unmodified from the IEEE text; licence note `LICENSE-IEEE-VITAL`; `tools/update-ieee-libs.sh` preserves them; yavs-sem exempts a call of `NOW` in them from E1830 and the access-result rule for pure functions | User decision 2026-10-19 (#118): do as the other simulators | `lib/SOURCES.md` "VITAL packages" |
| `ieee/1993/` is vendored byte for byte from the reference simulators' library trees (`std_logic_1164`, `std_logic_textio`, `math_*`, Synopsys, VITAL), except `numeric_std` and `numeric_bit`: those are derived from the Apache-2.0 2008 files (types over `STD_LOGIC`/`BIT`, 2008 additions deleted, the 1076.3 function set kept; every edit is in `SOURCES.md`), because the 1995 IEEE 1076.3 texts may not be sold or distributed for profit and are not shipped. `std/1993` derives from the 2008 copy by deletion only | User decisions 2026-10-23 (#629: add a 93 mode; #650: derive the packages instead of shipping the 1995 texts) | `lib/SOURCES.md` "1993 NUMERIC_STD and NUMERIC_BIT", `docs/design/vhdl-93.md` |
| Licence: Apache-2.0 (IEEE P1076 WG), redistributable with yavs; nothing from the reference simulators | Licensing | `lib/README.md` "Licensing" |

Decisions about these sources go in `SOURCES.md` (edits) or this section, in the same commit
(root `AGENTS.md` rule 24).

## 4. Invariants and pitfalls

- `NATIVE.md` is generated: change `tools/gen_native_md.py` and regenerate
  (`python3 -I tools/gen_native_md.py > lib/NATIVE.md`); `crates/yavs-sem/tests/native_symbols.rs`
  checks section 1 against `mangle::native_symbol`, and `yavs-interp` checks its reflection rows.
  `yavs-interp` rejects any native symbol NATIVE.md does not define.
- `yavs_sem::default_stdlib()` finds this tree: `$YAVS_STDLIB`, else `lib/` next to the
  executable or up to three parents, else (debug builds only) the checkout path (#43). Release
  archives ship it as `lib/` next to the binary.
- `cargo test --workspace` parses every file here (`crates/yavs/tests/lib_parse.rs`) and analyzes
  std/ieee in both revisions (`crates/yavs-sem/tests/stdlib.rs`).
- Reference simulator runs (`tools/check-sim1.sh`) follow root `AGENTS.md` rule 15.

## 5. How to work here

```sh
tools/update-ieee-libs.sh            # check: vendored tree equals the derivation of the pinned commit
tools/update-ieee-libs.sh --write    # rewrite lib/std and lib/ieee after changing derive_libs.py
python3 -I tools/gen_native_md.py > lib/NATIVE.md
tools/check-sim1.sh 2008              # reference simulator analysis of the tree (scratch under ~/.cache/rsim-libs)
cargo test -p yavs --test lib_parse && cargo test -p yavs-sem --test stdlib --test native_symbols
```

- No diagnostic codes.
