# Sources

Origin of every vendored file under `lib/std` and `lib/ieee`.

- **Upstream:** <https://opensource.ieee.org/vasg/Packages> ("IEEE 1076: VHDL Packages", Apache-2.0)
- **Pinned commit:** `dc691c8cf8a7365dd1d60895818631320996e983` (branch `release`; the tag
  `1076-2019` is `16a012320947d378611cc7457f64ed76cb52bac4`, the pin is two README/CHANGELOG-only
  commits later; `ieee/` and `std/` are identical at both).
- **License verification:** every one of the 26 upstream files under `std/` and `ieee/` carries the
  header "Copyright 2019 IEEE P1076 WG Authors ... Apache License, Version 2.0" (checked with
  `grep -a`), and the repository `LICENSE` is the Apache-2.0 text. Upstream sha256 of all 26 files:
  `UPSTREAM.sha256`. Sha256 of everything vendored here: `SHA256SUMS`.
- **Regenerate / verify:** `tools/update-ieee-libs.sh` (check) or `--write`. It re-clones at the pin,
  verifies `UPSTREAM.sha256`, re-derives the tree with `tools/derive_libs.py` and compares.
- **No NVC or GHDL files are used.** The rust_hdl `vhdl_libraries` copies were only compared against
  (see "Cross-check" in `README.md`).

## VITAL packages (not from VASG)

`ieee/{2008,2019}/vital_{timing,primitives,memory}{,-body}.vhdl` are the IEEE 1076.4 VITAL 2000
packages (`VITAL_Timing`, `VITAL_Primitives`, `VITAL_Memory`), vendored byte for byte, with the IEEE
headers, under yavs unit-file names (the loader finds a unit by file name):

| Vendored | Source file (`vital2000/`) |
|---|---|
| `vital_timing.vhdl`, `vital_timing-body.vhdl` | `timing_p.vhdl`, `timing_b.vhdl` |
| `vital_primitives.vhdl`, `vital_primitives-body.vhdl` | `prmtvs_p.vhdl`, `prmtvs_b.vhdl` |
| `vital_memory.vhdl`, `vital_memory-body.vhdl` | `memory_p.vhdl`, `memory_b.vhdl` |

- **Source:** the `vital2000` directory of a GHDL 7.0.0-dev checkout (`6.0.0.r418.g753dfcf0b`),
  which equals the 6.0.0 release copy and the `vital2000` library of the rust_hdl `vhdl_libraries`
  byte for byte. They are a copy of the IEEE files, taken as the published text.
- **Cross-check:** compared with the NVC copy (`lib/vital`): `prmtvs_p`, `memory_p`, `memory_b` are
  identical; `timing_p` has NVC's added `never_waits` attribute specifications; `timing_b` uses a
  local `NOW_TIME` instead of `NOW` plus whitespace; `prmtvs_b` marks 12 functions `IMPURE` (they
  call `NOW`). Those are NVC edits; the text both agree on is the IEEE text, which is what is
  vendored.
- **Licence:** IEEE copyright; the files carry no explicit licence grant. They are redistributed
  unmodified, as the other open-source VHDL simulators GHDL and NVC do. See `LICENSE-IEEE-VITAL`
  (shipped in the release archive).
- Not generated by `tools/derive_libs.py`; `tools/update-ieee-libs.sh` leaves them alone. Hashes
  are in `SHA256SUMS`.
- The pure functions that call `NOW` (`GlitchMinTime`, ...) are accepted because yavs-sem
  exempts a call of `NOW` in units `ieee.vital_*` from the purity check (E1830), and the same
  units from the access-result rule for pure functions (`VitalTimingDataInit`); user code still
  gets both (`docs/decisions.md`).

## Synopsys packages (not from VASG)

`ieee/{2008,2019}/std_logic_{arith,unsigned,signed,misc}{,-body}.vhdl` are the original Synopsys
packages (`STD_LOGIC_ARITH`, `STD_LOGIC_UNSIGNED`, `STD_LOGIC_SIGNED`, `STD_LOGIC_MISC`), vendored
byte for byte, with the Synopsys copyright header (user decision 2026-10-19, #117), always visible
in `ieee` with no flag.

- **Source:** the `synopsys` directory of a GHDL 7.0.0-dev checkout (`6.0.0.r418.g753dfcf0b`,
  `lib/ghdl/src/synopsys/`); `std_logic_misc` and its body come from its `v08/` subdirectory
  (the 2008 text, used for 2019 too). `std_logic_textio` is not vendored: since 2008 its
  procedures live in `ieee.std_logic_1164` (and `ieee/*/std_logic_textio.vhdl` exists already).
- **Split files:** upstream holds package and body of `arith`, `unsigned` and `signed` in one file
  (`library IEEE; use ...; package body ...` after the declaration), the loader finds a body in
  `<package>-body.vhdl`. Each file is cut at a line boundary just before the second `library IEEE;`
  line: `cat std_logic_X.vhdl std_logic_X-body.vhdl` equals the upstream file (checked). No byte is
  added or removed. `std_logic_misc` is split upstream already.
- **Cross-check** with the NVC copy (`lib/synopsys`), read only: `std_logic_unsigned` and
  `std_logic_signed` are byte-identical to it; `std_logic_arith` and `std_logic_misc` differ
  (NVC's own edits, e.g. the shipped warning texts and one body per file), and the NVC
  `std_logic_misc` is the one unit file for both revisions. Nothing was copied from NVC.
- **Licence:** see `LICENSE-SYNOPSYS` (shipped in the release archive).
- Not generated by `tools/derive_libs.py`; `tools/update-ieee-libs.sh` leaves them alone. Hashes
  are in `SHA256SUMS`. The sem checks accept the unmodified text without an exemption.
- Differential testbenches: `tests/corpus/synopsys/` (`tests/corpus/AGENTS.md`).

## Which revision is which

The VASG repository has a single release (published December 2019 with IEEE 1076-2019) and **no
separate 1076-2008 tree**. The official IEEE 1076-2008 package files (ieee.org downloads) are under
a different, non-Apache licence, so they are not used. Therefore:

- `ieee/2019/` is verbatim VASG (plus the two context files). The VASG ieee packages are the 2008
  packages with the later fixes; NVC analyzes all of them under both `--std=2008` and `--std=2019`.
- `ieee/2008/` has **the same bytes** as `ieee/2019/`. The directories are duplicated so each revision
  can be analyzed independently and diverge later without moving files.
- `std/2019/` is VASG with the edits below.
- `std/2008/` is **derived from VASG 2019** by removing the declarations 1076-2019 added.

## Edits to upstream files (all in `tools/derive_libs.py`)

| Target | Edit | Why |
|---|---|---|
| `std/2019/standard.vhdl` | `type INTEGER/REAL/TIME is range implementation_defined` replaced by `-9223372036854775807 to 9223372036854775807` (INTEGER), `-9223372036854775808 to 9223372036854775807` (TIME, so `TIME'low` is -2^63 fs as in the reference simulator) and `-1.7976931348623157e308 to 1.7976931348623157e308` (REAL) | upstream is a template, not valid VHDL; plan.md: 64-bit integers in 2019 mode |
| `std/2019/standard.vhdl` | CHARACTER position 160 `' '` became NBSP (byte 0xA0), position 173 `'-'` became soft hyphen (byte 0xAD) | upstream text lost these two literals (duplicate `' '` and `'-'`, every tool rejects the file) |
| `std/2019/standard.vhdl` | `type DIRECTION` renamed `RANGE_DIRECTION` (also in the comments that list implicit operations and range records; the record element `Direction` is unchanged) | LRM 1076-2019 16.3 and NVC name it `RANGE_DIRECTION`; the package source disagrees with the LRM (VI#97, open); user decision U-3 in `docs/design/lrm-checks.md` |
| `std/2008/standard.vhdl` | as above, then removed `type RANGE_DIRECTION`, `FILE_OPEN_KIND`'s `READ_WRITE_MODE`, `FILE_OPEN_STATE`, `FILE_ORIGIN_KIND`; INTEGER is `-2147483648 to 2147483647` | these are 1076-2019 additions; 2008 INTEGER is 32 bit |
| `std/2008/textio.vhdl` | removed `type LINE_VECTOR` | added by 1076-2019 (used by `env.DIRECTORY_ITEMS`) |
| `std/2008/env.vhdl` | reduced to `STOP`, `FINISH`, `RESOLUTION_LIMIT` (upstream licence header kept) | everything else in `env` is new in 1076-2019 |
| `ieee/*/ieee_std_context.vhdl`, `ieee_bit_context.vhdl` | written for yavs (VASG does not ship the contexts) | `IEEE_STD_CONTEXT` = `std_logic_1164` + `numeric_std`; `IEEE_BIT_CONTEXT` = `numeric_bit`, as in the 2008 LRM |

Other facts the consumer must know:

- `std/*/standard.vhdl` and `ieee/*/numeric_std.vhdl`, `numeric_bit.vhdl` contain **8-bit ISO-8859-1
  bytes** (CHARACTER literals, the copyright sign). The lexer must read VHDL source as Latin-1 bytes,
  not UTF-8. `lib/.gitattributes` turns off text conversion for these files.
- `std/*/textio.vhdl` and `env.vhdl` have **no package bodies**; all of their subprograms are native
  (see `NATIVE.md`). `std_logic_textio` is aliases only.
- The comments in `standard.vhdl` list the implicit operations; the analyzer creates them.
