yavs 0.10.0 makes `--threads` pay off on large RTL designs and share a CPU budget with other simulations, speeds up signal wiring, suggests close names in errors and checks more of the language.

- **Faster multithreaded runs:** `--threads N` speeds up large, flat RTL designs where thousands of processes wake on the same clock edge, and no longer slows down processor models or designs with a few dozen cheap processes per delta cycle.
- **Shared CPU budget:** with `--threads=N`, a simulation takes its extra threads from a token pool named in `MAKEFLAGS` (`--jobserver-auth=R,W` or `fifo:PATH`), so a test runner can share one CPU budget across simulations; a pool that cannot be used stops the run at the start with error `E0128`.
- **Faster wiring:** plain concurrent signal assignments (`a <= b;`, the wiring of stream and bus components) are copied by the simulator itself instead of running a process for each.
- **Close-name suggestions:** an unknown name now suggests a close one with its kind, for example "a signal with a similar name exists: `count`" for `cnt`, and points at its declaration.
- **Stricter checks:** more illegal code is now an error, among it malformed identifiers and literals, subprogram bodies that do not conform to their declarations, units used before their declaration in the same file and composite types with file elements; code that earlier versions accepted may need fixing.
- **Deferred constants:** a subprogram that names a deferred constant before its full declaration is now an error instead of reading the constant as zero during elaboration.
- **Range attributes:** `'left`, `'right`, `'low`, `'high` and `'ascending` of a range attribute, such as `t'range'left`, now work instead of being reported as not implemented.
