A single `yavs` executable with the IEEE libraries built in, online user documentation, and fixes.

## Features

- The `std` and `ieee` sources are built into the `yavs` executable, so a release is a single binary with no `lib/` directory next to it. `YAVS_STDLIB` still points yavs at a tree on disk.

## Bug fixes

- A constant in a package declaration whose value calls a function of the same package is reported as error E2114 again, also when only processes read it, instead of being evaluated before the package body exists. (#197)

## Documentation

- User documentation at <https://yavs.readthedocs.io>, with a version per release: installation, the command line and the release notes.
