yavs 0.21.1 fixes a wrong waveform in cycle mode where a delayed concurrent assignment follows a short glitch, and makes short tests start faster and idle designs in cycle mode run faster.

- **Fixed, wrong results in cycle mode (EXPERIMENTAL):** the logic that feeds a delayed concurrent assignment (`after`, `transport` or `reject`) below the top-level unit stays in the event simulation, so a glitch of one delta cycle adds or removes a transaction as in the normal mode.
- **Faster start of short tests:** a warm run restores more of the package state from the compilation cache instead of initialising it again, with or without `--cycle`.
- **Faster idle designs in cycle mode:** a clock edge that would change nothing in a small region is skipped, as the event simulation skips an idle process.

# Features

- A warm run restores the state of the packages before the first one that declares an array signal from the compilation cache, instead of initialising them again: short tests of VUnit test benches start faster, with or without `--cycle`.

# Bug fixes

- Cycle mode keeps the logic that feeds a delayed concurrent assignment (`after`, `transport` or `reject`) below the top-level unit in the event kernel, so a one-delta glitch removes or adds a transaction there as in the normal mode; before, such an assignment could show another waveform under `--cycle`.

# Miscellaneous

- Cycle mode skips a clock edge of a small region when the edge would change nothing, as the event simulation skips an idle process: test benches whose design waits idle for long stretches run faster.
