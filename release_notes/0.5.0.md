Adds aliases of external names and signal aliases, generic types, subprograms and packages, more aggregate and subprogram association forms, and skips PSL with a warning instead of stopping; shared variables of unprotected types are now an error unless `--relaxed` is given.


## Breaking changes

- Shared variables of a non-protected type (VHDL-93 style) are now an error (`E1904`) in VHDL-2008 and 2019; `--relaxed` turns it into the warning `W1904`. Signals and constants of a protected type, assignments to protected variables and operators on protected values are rejected (`E1905`). (#52)

## Features

- Aliases of external names (`alias s is <<signal .tb.dut.sig : std_logic>>;`) are analyzed for signals, constants and variables, and aliases of external signals in architectures, blocks and processes can be read, waited on and driven in simulation. (#19)
- VHDL-2019 protected types may declare private variables and method aliases that forward to them,
  and mode views can be declared in generic packages; designs using views, nested and array views
  and private variables simulate. (#32)
- VHDL-2019 conditional expressions (`x := a when c else b`, also in initial values, actuals and `return`), the conditional `return` and `unaffected` in variable and force assignments now analyze and simulate; in a VHDL-2008 file a conditional expression is reported as needing VHDL-2019. Functions with a VHDL-2019 named return value (`return r of t`) of an array type can use `r` as their result subtype, which each call takes from its target. (#33)
- Subprogram calls that associate a parameter element by element, such as `pr(x(0) => s)` or `swap(v(4) => a, v(5) => b)`, now run, also for unconstrained formals, which take their bounds from the elements named.
  A signal parameter can be associated in parts that lie in different signals, such as
  `drive2(x(1) => s1, x(0) => s0)` or a record parameter field by field: reads, drives, `wait on`
  and attributes such as `'event` work on the parts together. (#71)
- A port of mode `in` can now be associated with any expression, also one that reads signals
  (`n => x + y`, `v(1 downto 0) => not b`): the port follows the expression one delta later.
  Conversion functions of record ports (and arrays of records) in a port map, such as
  `w => to_wide(p)` or `to_pair(v) => q`, now simulate, in the same delta as the signals they convert. (#74)
- Entities with generic types, generic subprograms and generic packages (VHDL-2008 and 2019) now
  elaborate and simulate: each instance uses the actual types, subprograms and packages of its
  generic map. (#75)
- Positional aggregates may mix slices with elements, as VHDL-2008 allows: `(a, '1', b)` as a value, and `(hi, lo) := v` or `(hi, lo) <= v` as a target. (#89)
- PSL (default clock, property and sequence declarations, assert, assume, cover and restrict directives, verification units) no longer stops analysis: it is skipped with one warning (`W0004`) per design unit, and the rest of the design analyzes, elaborates and simulates. The PSL itself is not run; `-Werror=W0004` turns the warning back into an error. (#138)
- Signal parameters of record types and of arrays of records (in, out and inout), package signals of record types, and signal attributes such as `'event`, `'last_value`, `'stable` and `'delayed` of records and of parts of arrays of records now simulate. (#215)
- Open and unassociated `in` ports of an unconstrained array subtype that have a default expression are accepted and take the bounds of the default. (#218)
- Generic map actuals, constants and signal bounds can use multi-dimensional aggregates, arrays
  of records or arrays, records with array elements, shift operators and `TO_STRING` of real and
  physical values during elaboration; impure initial values of these types run in declaration order. (#220)
- Components and blocks with generic types, generic subprograms and generic packages now elaborate
  and simulate, bound by default, by a configuration specification or by a configuration
  declaration, and an architecture of an entity with generic types may hold configuration
  specifications. (#222)
- A subprogram whose header has both a generic list and a generic map is an instance of itself and can be called with the mapped profile. A type, subprogram or package interface in a parameter list is now reported as error `E1232`. (#227)
- Subprogram calls accept conversion functions and type conversions in their associations (`set(to_real(x) => r)`, `inc(to_real(x) => to_int(r))`), and conversions that the parameter's class or mode does not allow are reported with a dedicated error. (#229)
- Named aggregates may take VHDL-2008 array values under range choices, such as `(7 downto 4 => a, others => '0')`, and aggregates of arrays with unconstrained elements may mix rows and slices. Signals of arrays of arrays can be named below a slice, such as `m(0 to 1)(0)`, and waited on through an alias with other bounds. (#230)

## Bug fixes

- `for others : c use entity ...` in a configuration no longer reports E1702 for an instance that
  an earlier component configuration names and a configuration specification binds.
  An entity instance that leaves a generic subprogram to its `is <>` default now uses the
  subprogram visible at the instance instead of being dropped without a message. (#75)
- Nested names of signals of arrays of arrays, such as `m(i)(j)`, `m(i)(7 downto 4)` and `g(i, j)`, can now be assigned, passed, aliased and waited on, and assigning a whole element such as `m(i)` drives all of it. (#89)
- A constant without a value (`constant c : bit;`) in an architecture, process, subprogram or package body is now rejected with `E1224`; only a package declaration may hold a deferred constant. A deferred constant whose package body lacks the full declaration is rejected with `E1230`. (#213)
- A negated literal at the 64-bit minimum, such as `-9223372036854775808` or `-9223372036854775808 fs`, is now accepted for integer and physical types; the literal without the minus is still rejected as too large. (#214)
- Signals of records and arrays of records whose field bounds come from the initial value, a partially constrained subtype or a port's actual now simulate, and a static signal element assigned more than once in a process no longer stops with an internal error. (#215)
- A procedure or function declared inside a method of a protected type body can now call the other methods of the body and use its variables; they act on the object of the enclosing method call. (#221)
- An unconstrained array formal that is associated element by element, in a subprogram call or a port map, now needs every element between the lowest and highest index named, each exactly once. A gap is reported as a missing actual and a repeated element as an association made twice, each with a note naming the indices. (#224)
- A subprogram instantiation with `pure`/`impure`, a parameter list, a generic clause or a `return` before `is new` is now a syntax error (`E0002`) instead of being silently accepted. (#225)
- Length mismatches of arrays at run time are reported as "value length 4 does not match target length 3", the wording of the other simulators.
  A named aggregate assigned to a constrained target takes the target's direction, so `v := (7 => '1', 6 downto 0 => '0')` with `v : bit_vector(7 downto 0)` sets `v(7)`. (#230)
- A process calling a procedure with a `signal out` parameter on several different elements or slices of one signal now drives each of them, instead of stopping with "target outside the driver". (#231)
- A package body that declares a name again which its package already declares (a constant, signal, type or subprogram of the same profile) is now rejected with `E1101`, pointing at the first declaration; deferred constants completed in the body stay legal. (#232)
- A port actual written `inertial` is an expression actual even when it is a signal name: the port follows the signal one delta later, through an implicit process (LRM 6.5.6.3). (#233)
