Tier policy: under `--tier=auto`, what a run decides for the next one follows the work it did, counted in instructions where the system provides the counter, instead of its CPU time, so a busy machine no longer changes those decisions. Repeated runs of a testbench now settle into their fast state in every fresh cache: the time a candidate was seen adds up across runs, and an early compile is judged by a run that linked it rather than one that paid for it. Profiles stored by an earlier version are ignored once.
