Tier policy: under `--tier=auto`, more of what a run spends its time in is compiled: subprograms that a compiled process calls through its specialised copies, such as the many procedures of a processor model, are compiled too, and a subprogram that loops for a long time in one call, such as a test's set-up at time 0, is compiled early in the next run. A simulation no longer enters compiled code at a subprogram return that the interpreter runs anyway, and with `--tier-compile=wait` the first run of a testbench whose processes call large trees of procedures no longer sometimes compiles them in its last moments, so it takes about the same time every time.
