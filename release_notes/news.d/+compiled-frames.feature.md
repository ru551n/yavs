Compiled code (`--tier=llvm`, `--tier=auto`) calls small functions that need no interpreter frame directly, with their arguments and locals in machine registers and on the native stack; such a frame becomes an interpreter frame only when the interpreter needs one, so error messages, call stacks and collections are unchanged. Compiled code is also entered at the first instruction the interpreter executes in a function instead of waiting for its first jump, and `deallocate`, array fills and protected-object calls in compiled code no longer go through the interpreter's generic dispatch.
