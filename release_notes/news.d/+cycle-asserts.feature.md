Cycle mode now evaluates the `assert` and `report` statements of the processes it runs, clocked ones at their clock edge and combinational ones on settled values, with the normal mode's messages, severities and their effect on the run, so a design that ends its own test does so in cycle mode too. A concurrent `assert not (rising_edge(clk) and ...)` is checked at that clock edge. The new `yavs run --no-asserts` drops the asserts and reports below the top-level unit, in the normal mode and in cycle mode, for speed; the test runner package takes it as the sim option `yavs.no_asserts`.
