Under `--cycle`, logic feeding a process with an incomplete sensitivity list (a register's asynchronous reset branch included), or a process that keeps a value of an earlier run but stays out of the region for another reason first (a `'Z'`, say), stays in the event simulation, as it already did for latches and state, and so does logic feeding a latch written as feedback (`l <= d when en = '1' else l;`): such a process saw other values than in the normal mode.
