With `--cycle --two-state` a process below the top-level unit that compares with a metavalue literal (`= 'X'`, a `case` choice such as `"0X"`) now runs cycle-based instead of staying in the event kernel: a two-state value never equals the literal, so `x = 'X'` is false and `assert clk /= 'U'` holds. Without `--two-state` such a process stays in the event kernel.
