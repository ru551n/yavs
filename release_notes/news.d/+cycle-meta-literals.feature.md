With `--cycle --two-state` a process below the top-level unit that compares with a metavalue literal (`= 'X'`, a `case` choice such as `"0X"`) now runs cycle-based instead of staying in the event kernel: like an assigned one, the literal reads as the value of `--init-x`, `0` without it, and the region report counts these literals per process. Without `--two-state` such a process stays in the event kernel.
