In cycle mode a process below the top-level unit that compares with a metavalue literal (`= 'X'`, a `case` choice such as `"0X"`) now runs cycle-based instead of staying in the event kernel: like an assigned one, the literal reads as the value of `--init-x`, `0` without it, and the region report counts these literals per process; `--cycle-exact-meta` keeps the old rule.
