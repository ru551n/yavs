Plain `--cycle` keeps the normal mode's nine `std_ulogic` values for the whole run: metavalues, `'Z'` and the `'U'` of registers without a start value reach the testbench as in the normal mode, and the results differ from it only in the scheduling and in the `ieee` library warnings, which cycle-based processes do not give. It is slower than `--cycle --two-state`, which computes with `0` and `1` only.
