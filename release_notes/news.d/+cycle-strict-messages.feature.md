Every reason `--cycle-strict` refuses a process is now an error that names the construct that is not supported, points at the statement that causes it (and at the other process or signal when the reason spans processes), lists the processes it keeps out, and says why and how to fix it, or that it is a limitation of yavs. Each reason has its own code (E4128 to E4139 are new), the errors are sorted by file and line, and `--cycle-report` uses the same words.
