With `--cycle --cycle-exact-meta`, a register, variable or memory word without a start value now shows the testbench `'U'` until its value no longer depends on it, as in the normal mode, for up to 1024 clock edges; an `'X'` reaching the region shows as `'X'`, and a combinational choice on such a value (`when ... else`, `to_integer` as an index) takes the branch the region's own values take. The default `--cycle` is unchanged.
