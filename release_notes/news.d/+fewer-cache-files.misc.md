Compilation cache: a cold run writes far fewer files, which Windows with real-time antivirus scanning gains from most: compiled code is created in place instead of through a temporary file and a rename (on Windows too), the lists of compiled functions are stored when the run stops and from the idle compile thread at most every two seconds instead of after every compile, an entry stored again with the very bytes it holds is not rewritten, and reading an entry refreshes its time only when it was not used in the last seconds. A run that crashes or is killed loses at most about two seconds of list lines; the next run links or recompiles those functions.
