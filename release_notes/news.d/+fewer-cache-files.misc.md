A cold run writes far fewer files into its compilation cache: compiled code is created in place instead of through a temporary file and a rename (on Windows too), the lists of compiled functions are stored when the run ends (by any route, also Ctrl-C) and when compiling pauses, instead of after every compile, and reading an entry refreshes its time only when it was not used in the last seconds. Cold runs on Windows with real-time antivirus scanning gain the most. An entry stored again with the very bytes it holds is not rewritten. A run with the compiled tier ends on its first Ctrl-C or SIGTERM through yavs itself, with exit status 130, also on a plain terminal, after storing the lists.
