`yavs run --init-unset=0|1|random[:SEED]` gives signals and process variables without an initial value a start value instead of `'U'`, and `--init-x` gives the metavalue literals a design assigns a value, so a test shows whether a design depends on a register without reset or on a "don't care"; both work in cycle mode, print the seed of `random` so a run can be repeated, and are the sim options `yavs.init_unset` and `yavs.init_x` of vunit-yavs.
