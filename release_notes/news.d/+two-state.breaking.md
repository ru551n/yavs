Cycle mode keeps metavalues by default now: plain `--cycle` and `--cycle-strict` run with the rules `--cycle-exact-meta` gave in 0.21, so processes that would hide a metavalue from the testbench stay in the event kernel again. The new flag `--two-state` (vunit-yavs sim option `yavs.two_state`) selects the two-state values plain `--cycle` gave in 0.21, and `--cycle-exact-meta` is removed. To keep the 0.21 results, add `--two-state` to `--cycle`; drop `--cycle-exact-meta`. `--cycle-strict` only changes which processes must join, not the values. `--two-state` also works without cycle mode: the design below the testbench then holds only `0` and `1` in the event kernel, metavalues it reads counting as `0` and its metavalue literals taking `--init-x`.
