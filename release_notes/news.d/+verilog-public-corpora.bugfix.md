`yavs analyze` now reads Verilog that real designs use and it refused: `int`, `bit` and `string` as port, argument and parameter names, empty ports, a backtick in an escaped identifier, comments and line ends in the arguments of a macro definition, long `? :` chains and legacy protection markers in a module header. It rejects an input port declared again as `reg`, warns about a unary operator applied to another one (`W4208`) and a header port declared again in the body (`W4209`), reports the fault-simulation directives as ignored (`W4016`) and a value on an input port as accepted (`W4017`).
