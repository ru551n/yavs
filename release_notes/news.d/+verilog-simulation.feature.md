A VHDL testbench can instantiate a Verilog module through a component of the module's name and simulate it: registers, combinational logic, parameters set from generics (also strings and wide vectors), `always` and `initial` blocks with event and delay controls, blocking and non-blocking assignments and the 4-state operators of the standard. `-L LIB` on `elab` and `run` adds libraries to the search for such modules; a Verilog construct that is not supported yet stops elaboration with an error that names it.
