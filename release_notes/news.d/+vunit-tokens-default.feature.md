The test runner package `vunit-yavs` starts its token server by default when `-p N` is below the CPU count, with one slot for each CPU the run may use: each test slot keeps its CPU and the idle ones are lent, so every simulation runs with `--threads=auto` and takes them only while its threads gain, and threads never keep more CPUs busy than the machine has. `--yavs-no-jobserver` or `VUNIT_YAVS_JOBSERVER=off` turns it off.
