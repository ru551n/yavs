Under `--tier=auto` a run now waits while a function compiles, so as many simulations as cores no longer lock up the computer with one busy compile thread each; `--tier-compile=background` (sim option `yavs.tier_compile` in the test runner package) keeps the old compile thread alongside the run, now at the lowest priority of the system. A short run that waits compiles only what it spent its compile time in, so it loses little to the compiles.
