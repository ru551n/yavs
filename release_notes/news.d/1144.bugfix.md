`=`, `/=` and (VHDL-2019) the ordering operators on an array of reals (`real_vector` or any array of a floating-point type) compared the bytes of the elements, so `(-0.0, 1.0) = (0.0, 1.0)` was false and arrays with negative elements ordered wrongly; they now compare the elements as reals, as the scalar and record compares already did.
