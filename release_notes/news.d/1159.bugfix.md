VHPI now sizes arrays and reads user attribute values whose bounds or value depend on a generic through nested arithmetic (`2 * N + 1`, `(N + 1) / 2`, `N * 2 - 1`), and reads a constant whose value is such an expression (`constant c : integer := N + 1`) even when nothing in the design reads it; before, only one operation on the generic gave a size and an attribute value, and these constants had no value.
