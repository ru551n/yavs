A scalar `out` or `inout` variable parameter whose value does not belong to the subtype of its actual when the call returns, such as 10 copied back into a variable of `integer range 0 to 9`, is now a run-time range error at the call, and the value of an `inout` actual is checked against the formal's subtype before the call. Before, the value was copied back unchecked. Record fields, array elements and enumeration, physical and floating-point subtypes are checked the same way.
