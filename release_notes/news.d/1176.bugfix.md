A scalar variable of a protected type body whose range reads an earlier variable of the body (`variable q : integer range 0 to k`) is accepted: each object evaluates the range once, when it is created, so a later change of `k` does not change which values `q` accepts, and an impure function in the range is called once per object.
The debugger, `describe` and the other listings of a protected object's state show only the variables of the body, not the bounds the object keeps for such a range.
