Code coverage: `yavs run --cov[=FILE]` counts statements and branches (`if`/`elsif`/`else`, `case` alternatives, conditional and selected assignments, loop bodies) per instance and writes a coverage database; `yavs cov merge` adds databases of several runs together, and `yavs cov report` prints a text summary with every uncovered line and writes a Cobertura XML report with `--cobertura FILE`.
