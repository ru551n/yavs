VHPI plugins can read the address an access variable of a process designates with `vhpiPtrVal`. `vhpiParent` of a sequential statement gives the statement or process around it. `vhpiLocalLoads` and `vhpiOptimizedLoads` also list the processes that read a signal. An alias of a record field, an array element or a slice reads, writes and reports value changes as the part of the object it names.
