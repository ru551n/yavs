Length mismatches of arrays at run time are reported as "value length 4 does not match target length 3", the wording of the other simulators.
A named aggregate assigned to a constrained target takes the target's direction, so `v := (7 => '1', 6 downto 0 => '0')` with `v : bit_vector(7 downto 0)` sets `v(7)`.
