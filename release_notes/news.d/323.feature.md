The debugger (`yavs run --dap`) forces, deposits and releases signals and sets variables: "Set Value" in VS Code's Variables view, the extension's force, deposit and release commands, or the `yavs/force`, `yavs/deposit` and `yavs/release` requests, with values written as VHDL literals such as `x"A5"` or `(a => 1, others => '0')`.
