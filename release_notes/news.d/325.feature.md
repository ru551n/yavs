`yavs run --dap` now works together with `--wave` and `--vhpi`, and streams live waves: a client subscribes to signals and variables with `yavs/waveSubscribe` and receives their changes per time step as `yavs/waves` events, without ever slowing the simulation down. Values are compact: base64 of the same value bytes the waveform file gets, and the subscribe response gives each signal's `encoding` so a client can decode them.
