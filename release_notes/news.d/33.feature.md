VHDL-2019 conditional expressions (`x := a when c else b`, also in initial values, actuals and `return`), the conditional `return` and `unaffected` in variable and force assignments now analyze and simulate; in a VHDL-2008 file a conditional expression is reported as needing VHDL-2019. Functions with a VHDL-2019 named return value (`return r of t`) of an array type can use `r` as their result subtype, which each call takes from its target.
