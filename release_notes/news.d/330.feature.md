A VHPI foreign function can return an array: the plugin sets an unconstrained result's length with `vhpi_put_value` in `vhpiSizeConstraint` mode, then puts the value. Foreign subprograms can also take records, access values and signals; an `out` signal parameter is driven with `vhpi_schedule_transaction` on its driver. A plugin can implement a whole architecture (`attribute foreign of arch : architecture is "VHPI library model"`): it creates a process and drivers with `vhpi_create` and drives the ports with `vhpi_schedule_transaction`.
