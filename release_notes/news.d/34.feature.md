Packages and package bodies can be declared inside packages, package bodies, entities, architectures, blocks, generates, processes and subprograms, generic ones included: their objects belong to the enclosing region, and local generic packages can be instantiated there, in nested regions and through an instance of an enclosing generic package. A signal or shared variable declared in a process or subprogram, directly, in a package there or through a package instance there, is now an error.
