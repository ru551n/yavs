`yavs cov report --html DIR` writes a self-contained HTML coverage report: totals, a row per instance and file, and per source file the hit count of each line, missed statements, branch arms and toggles with copyable exclusion rows, excluded items greyed with their reason, and the tests that hit each item.
The HTML coverage report also writes a "missed only" page per source file (`src-N-missed.html`, linked from the index and the file page) that lists just the lines with a missed or excluded item, so large designs stay usable without scripts.
