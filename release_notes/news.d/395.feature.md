The common `std_logic_1164`, `numeric_std`, `math_real` and Synopsys `std_logic_arith` functions (logic gates on vectors, `+`, `-`, `*`, comparisons, `resize`, conversions, shifts, `rising_edge`, `sqrt`, `exp`, `log`, `sin`, `cos`, `floor`, `**`) run natively and are many times faster than their VHDL bodies, with the same bounds, warnings and error reports; set `YAVS_NO_NATIVE_IEEE=1` to run the library bodies instead (`math_real` results may differ in the last digits).
