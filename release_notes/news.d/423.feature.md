With `--dap` and `--wave`, the waveform file is flushed at every debugger stop, so a waveform viewer open next to the debug session shows every change up to the stop.
A run started with `--dap=PORT` says on stderr that it waits for a debugger and holds the simulation until a client attaches, so an editor can attach to a run started by a test runner; the VS Code extension has an "Attach to yavs" snippet and the usage guide a recipe for debugging one test.
