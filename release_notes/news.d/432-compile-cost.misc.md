The LLVM tier compiles much faster: functions get a short optimisation pipeline (compute loops keep the full one), very large functions use the cheap code generator, less code is generated for memory accesses and exits, `--tier=auto` leaves the native-frame code of a hot function to the compiled callers that need it and loads LLVM only when the first function is compiled, so hot code is compiled sooner and runs that never get hot start faster. `--tier=llvm` of a design with large packages (the floating-point package) takes seconds instead of a minute and more.
