`--tier=auto` compiles at O2 only, when the compile time it would spend stays within about two percent of the time the run spent in interpreted code (twice that for plain compute loops), together with the small functions the hot one calls, so a short run costs what `--tier=interp` costs and a long one gains where compiled code is faster; compiling a design takes a third less time because addresses are looked up in one call instead of generated code.
