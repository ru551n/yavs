Simulations of vector-heavy clocked designs run faster: the address arithmetic of signal element and slice accesses, the waveform set-up of an assignment and the reads of single elements are fewer, cheaper steps in the interpreter, with identical results and the same error messages.

Designs with many instances of a process that index signals by a generic or generate index run faster too: that arithmetic and its range checks are done once per instance, and a failing check still fails with the same message at the same time.

Clocked processes that assign vectors (shift registers, feedback, copies of a variable to a signal) and the `and`, `or`, `xor`, `not` operators of `numeric_std` on `unsigned` and `signed` vectors run faster, with identical results, messages and length errors.

Clocked processes run a few percent faster in the interpreter: the statement bookkeeping around the edge test and the wait and the jump back to the start of the process are no longer separate steps, and reads of process variables take a shorter path.
