Testbenches that pass strings and arrays of changing lengths to subprograms, loops in subprograms, default values and `others` choices of `std_logic_vector`s and `case` statements over them run faster: array layouts are computed without allocating, scalar variables, parameters and loop bounds that nothing else can reach are kept in registers instead of frame memory (a debugger started with `--dap` still sees every variable in memory), and a logic array is filled or compared a plane word at a time.
