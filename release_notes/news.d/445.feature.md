VHDL-2019: any expression of a range record type (`R'RECORD`) now works as a range, also when its value is known only at run time: an object, a function call such as `for i in f(n) loop` or `bit_vector(f(n))`, a qualified expression or an operator, in an index constraint, a range constraint, an array type, a loop, a slice or a for-generate.
