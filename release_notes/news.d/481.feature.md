Warm runs start faster: the compilation cache maps its entries into memory instead of reading and copying them, and the generated code of a function is decoded when the function first runs. A short test of a verification library takes up to 15% less CPU time on its warm runs.

A yavs built with the `clift` feature can run compiled code without an LLVM install: `--tier=clift` translates every function before time 0 and `--tier=clift-auto` translates the functions that become hot while the simulation runs; the output is the interpreter's. `--tier=auto3` (both features) translates warm functions with Cranelift and compiles those that stay hot again with LLVM.
