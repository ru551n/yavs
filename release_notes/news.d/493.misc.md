Testbenches that keep queues and buffers in protected objects behind many small subprograms, as verification libraries do, run noticeably faster: layout facts of record and array types are known before the run, protected objects and shared variables are read and written directly, a call no longer reloads its parameters, and calls of small subprograms that only pass their arguments on are replaced by their code (error call stacks and `get_call_path` still list them). `YAVS_NO_INLINE=1` turns the last one off.
