A VHDL-2008 file in a design elaborated with the VHDL-2019 std/ieee now gets an error when it names a std or ieee declaration that VHDL-2008 does not have (such as `std.env.tool_name` or `std.reflection`), and a warning (`W1008`, escalatable with `-Werror`) where an INTEGER bound such as `integer'high` changes value under the 64-bit VHDL-2019 INTEGER.
