A process without a wait statement or sensitivity list no longer hangs the run silently: its activation is bounded, and after the limit the process fails with `E3009` explaining that it never suspends so simulation time cannot advance. Previously such a run spun forever at time 0 with no diagnostic beyond the startup warning. The bound also holds when the process has been compiled (`--tier=auto`, `--tier=llvm`), where it previously ran until the host ran out of memory.
