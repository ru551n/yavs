An array index constraint is now checked against the index subtype whatever form its range has and wherever it appears: an attribute range (`variable s : string(x'range);`), the constraint of a record element or of an array's element subtype, and a signal's constraint whose bound comes from a generic (`signal s : string(g to 3);` with `g = 0`). A bound outside the index subtype (`0` for `string`, whose index subtype is `POSITIVE`) fails at the declaration instead of being accepted.
