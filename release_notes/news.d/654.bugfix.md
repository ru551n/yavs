An `in` port or parameter used as the actual of an `out`/`inout`/`buffer` formal in a port map is now a mode error (`E1360`) in both the component and the entity form, and also for a part of the formal in an individual association (`o(0) => p1`), instead of being accepted (component, part) or reported as a misleading multiple-sources error (entity). An expression as the actual of such a part is reported as for a whole formal instead of stopping elaboration with an internal error.
