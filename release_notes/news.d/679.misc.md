Compiled code (`--tier=llvm`, `--tier=auto`) now lives in one block of memory backed by huge pages where the kernel allows it, and its entry dispatch and hot-path branches are laid out to cost fewer instruction fetches. `YAVS_LLVM_ARENA=0` returns to the linker's own placement. The compiled code of large processes is smaller and faster: calls into the runtime are short, blocks are laid out in execution order and the low half of a 64-bit load is a 4-byte load. `YAVS_LLVM_CODEMODEL=large` returns to the previous addressing.
