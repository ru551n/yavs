Coverage can now measure conditions and logic expressions: `--cov-kind=condition,expression` counts, for every `if`, `elsif`, conditional assignment, loop and `exit`/`next` condition and every boolean assignment with two or more inputs, whether each input at each value decided the result alone (focused expression coverage). Missed rows are listed by `yavs cov report --uncovered`, shown as a table per condition in the HTML report, and can be excluded per row in text or YAML exclusion files. Inputs that are constant after elaboration (generics, constants, literals) get no rows, so no row is unreachable.
