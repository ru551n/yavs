Designs with many instances of the same process (adder trees in generate loops) run faster: concurrent assignments that only convert a signal between array types (`std_logic_vector(u)`, `unsigned(v(3 downto 0))`) are copied by the kernel, a carry-in aggregate such as `(0 to 0 => cin)` is straight code, and `--tier=auto` compiles instances whose generated code is the same once.
