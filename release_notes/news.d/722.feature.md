Calls of pure functions of one character, enumeration or small integer argument that choose their result with a `case` or an `if` chain (hex digit to value, character to nibble, state to code) are answered from a result table made when the function is lowered, so parsers that call them for every character of a large input start up faster. Values whose evaluation reports or fails still call the function, so output and reports are unchanged; `YAVS_NO_CASETAB=1` turns the tables off.
