A port of mode `in` can now be associated with any expression, also one that reads signals
(`n => x + y`, `v(1 downto 0) => not b`): the port follows the expression one delta later.
Conversion functions of record ports (and arrays of records) in a port map, such as
`w => to_wide(p)` or `to_pair(v) => q`, now simulate, in the same delta as the signals they convert.
