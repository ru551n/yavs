Copy and fill loops over the elements of logic vectors (row and column extraction, conversions between vector and matrix types) now run their iterations at once in compiled code too, as they do in the interpreter, with the loop checked and planned by the generated code itself instead of a runtime helper. `--tier=auto` compiles hot processes that loop earlier, makes the interpreter-entry code of a compiled function only when a run needs it, and compiles a specialised copy of a process only when that copy pays for itself. Compiling a function that runs on native frames no longer slows down the interpreted code that calls it for the rest of its activation. `--tier=auto` compiles native compute loops sooner in a first run and no longer starts a compile whose callees cost more than the run can repay.
