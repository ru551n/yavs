Simulations run side by side can share one CPU budget on Linux and Windows: with `YAVS_TOKENS` naming a test runner's token server, `--threads=N` runs its extra threads only on tokens the server lends, and every token comes back when the simulation ends, even when it is killed. The `vunit-yavs` package's `--yavs-jobserver` uses it and lends the idle `-p` slots to the running tests.
