`yavs run --threads=N` can share one CPU budget with other simulations: when `MAKEFLAGS` names a token pool (`--jobserver-auth=R,W` or `fifo:PATH`), a simulation runs its extra threads only on tokens it takes from the pool, and gives them back when it no longer needs them. A pool that cannot be used stops the run at the start with error `E0128`, which names the cause and the fix.
