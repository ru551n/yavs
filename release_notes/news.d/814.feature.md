A file analysed with `--std=93` is now checked against the VHDL-1993 rules that VHDL-2008 relaxed: aliases of multidimensional arrays, unconstrained element types, `buffer` port associations with `out` or `inout` ports, packages inside declarative parts and array values as parts of aggregates are errors that name the 1993 rule. 2008 and 2019 files are unchanged.
