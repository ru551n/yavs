`yavs run --surfer` shows the waveform in the Surfer viewer while the run writes it, starting Surfer or connecting to a running one. In a debug session the cursor follows the stops, breakpoints leave markers, the stopped process's signals are coloured and go to declaration opens the source; `wave add` and `wave cursor` work at the console, and `vunit-yavs --yavs-surfer` and the VS Code `surfer` setting use it.
