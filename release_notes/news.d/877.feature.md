`yavs cov report` prints readable text: source paths relative to the current directory or `--root`, branch arms named from the source (`if rst = '1'`, `elsif`, `else`, `when IDLE`, `(no arm taken)`), one toggle wording and aligned columns. New `--kind=LIST`, `--total` (only the percentage) and `--fail-under=PCT` (exit status 1 below it) make coverage a CI gate, and the `vunit-yavs` package collects, merges and checks coverage with `enable_coverage`, `--yavs-cov`, `results.merge_coverage()`, `--yavs-cov-html` and `--yavs-cov-fail-under`.
