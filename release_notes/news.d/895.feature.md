`yavs lint` reports what can be proved wrong about a design before it is simulated: a process that can never suspend, a function that can fall through, unreachable statements, vector width mismatches, indexes out of range and division by zero, with configuration, waivers and JSON, SARIF, JUnit, Code Climate and SonarQube reports. Advisory, experimental and policy rules (latches, multiple drivers, combinational loops, state machines, clock and reset crossings, and more) run when a configuration asks for them, and `--facts` writes state machines and clock and reset domains as JSON.
