`yavs run --interactive` runs a simulation from a `yavs>` prompt (run, step, examine, force, breakpoints, restart to time 0 without recompiling, source), `--do` runs the same commands as a script, and they work in the VS Code Debug Console. A test runner can add its own commands through a documented hook; `vunit-yavs --yavs-interactive` uses it for the `vunit_*` commands.
