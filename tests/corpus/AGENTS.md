# AGENTS.md: tests/corpus/ (differential simulation corpus)

Read the root `AGENTS.md`, `tests/AGENTS.md` and `tools/difftest/AGENTS.md` first. The full
contract (header, canonical form, ignore set) is `tools/difftest/README.md`.

## 1. Purpose and boundaries

- Self-checking VHDL testbenches, grouped by directory (`scalar arith process delta sigassign
  postponed report env resolution force composite access protected textio generics hierarchy
  reflect`), each with the NVC reference output `<name>.expected` in canonical form. The M2 check
  is that yavs matches every one at 1, 4 and 4 shuffled threads.
- `RESULTS.md`: generated by `tools/difftest/report.sh`; do not edit by hand.
- Consumers: `tools/difftest/difftest.py` (through the CLI) and
  `crates/yavs-lower/tests/corpus.rs` (in-process; its `PASS` list must match exactly).

## 2. Design decisions that bind this module

| Decision | Why | Source |
|---|---|---|
| Written from scratch, never copied from NVC/GHDL tests | Root rule 6 | `tools/difftest/README.md` "Corpus" |
| Header `-- difftest: top=NAME [std=] [stop=] [exit=N] [ref=hand] [ignore=...]` in the first 15 lines | Harness contract | README "Test header" |
| Self-checking (`assert ... severity failure`) and deterministic; avoid implementation-defined output (`real'image` outside `scalar/real_image.vhd`, non-ASCII) | Strict comparison | same |
| `ref=hand`: NVC is wrong, `.expected` hand-corrected to the LRM result, with a comment saying why | LRM policy | same; e.g. `reflect/multidim`, `composite/unconstrained_records` |
| `ignore=order` only with a comment, for same-cycle reports of different processes | LRM leaves the order unspecified | README "Ignore set" |

## 3. How to work here

```sh
python3 tools/difftest/difftest.py --bless --filter 'group/name'   # write .expected with NVC (rule 15 wrapping is built in)
python3 tools/difftest/difftest.py --candidate yavs --threads 4 --filter 'group/'
cargo test -p yavs-lower --test corpus
tools/difftest/report.sh                                           # refresh RESULTS.md
```

- A new test: `.vhd` with a header, `.expected` from `--bless` (check the exit status matches
  `exit=`), and, once yavs passes it, its name in `PASS` of `crates/yavs-lower/tests/corpus.rs`.
- Under 5 minutes per test (root rule 16); shrink the scenario, never weaken assertions.
