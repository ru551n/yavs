# AGENTS.md: tests/corpus/ (differential simulation corpus)

Read the root `AGENTS.md`, `tests/AGENTS.md` and `tools/difftest/AGENTS.md` first. The full
contract (header, canonical form, ignore set) is `tools/difftest/README.md`.

## 1. Purpose and boundaries

- Self-checking VHDL testbenches, grouped by directory (`scalar arith process delta sigassign
  postponed report env resolution force composite access protected shared textio generics
  hierarchy reflect implicit ieee psl held`), each with the reference simulator output `<name>.expected` in canonical form. The M2 check
  is that yavs matches every one at 1, 4 and 4 shuffled threads.
- `RESULTS.md`: generated by `tools/difftest/report.sh`; do not edit by hand.
- Consumers: `tools/difftest/difftest.py` (through the CLI) and
  `crates/yavs-lower/tests/corpus.rs` (in-process; its `PASS` list must match exactly).
  `tools/pgo/train.py` runs every testbench here (`analyze`, then `run` at `auto` and `clift`, exit status per its header) as the
  analysis and elaboration part of the profile-guided build: a testbench that fails there, writes files outside its directory or runs long
  stops that build.

## 2. Design decisions that bind this module

| Decision | Why | Source |
|---|---|---|
| Written from scratch, never copied from the reference simulators tests | Root rule 6 | `tools/difftest/README.md` "Corpus" |
| Header `-- difftest: top=NAME [std=] [stop=] [relaxed] [exit=N] [ref=hand] [ignore=...]` in the first 15 lines | Harness contract | README "Test header" |
| Self-checking (`assert ... severity failure`) and deterministic; avoid implementation-defined output (`real'image` outside `scalar/real_image.vhd`, non-ASCII) | Strict comparison | same |
| `ref=hand`: the reference simulator is wrong, `.expected` hand-corrected to the LRM result, with a comment saying why | LRM policy | same; e.g. `reflect/multidim`, `composite/unconstrained_records` |
| `implicit/` covers the implicit (predefined) operations end to end (#163); `hand_edges` (`ref=hand`) holds the negative `sla`/`sra` and null `&` cases where the reference simulator 1.23 deviates; `?<` with '-' and `FILE_CANSEEK` of a closed file (the reference simulator segfaults) are left out | Comparable references | yavs-interp, 2026-10-18; `docs/decisions.md` "Implicit operation natives" |
| `ieee/`: one `<package>_ops` test per IEEE package body, 2008 plus a `_2019` copy; reals printed as integers scaled by 1e6, checked with a 1e-6 tolerance (math_real/math_complex bodies are approximations) | Strict comparison, implementation-defined real text avoided | #94 |
| `ieee/vital_model`: a zero-delay VITAL level-1 style flip-flop (VitalPathDelay01, VitalSetupHoldCheck) and VitalNAND2/VitalMUX2, 2008 plus `_2019`; only sim1 is a reference (sim2 needs `-frelaxed` for the VITAL packages) | Exercises the built-in VITAL packages | #118 |
| `synopsys/`: black-box testbenches (generated by `synopsys/gen.py`) for the built-in `std_logic_arith`/`unsigned`/`signed` operators on every operand shape; reference output from the reference simulator (its own copy of the packages: warning texts differ from the vendored original, see `lib/SOURCES.md`); outputs over 1 MB are stored as `.expected.gz` (difftest reads both) | Exercises the built-in Synopsys packages | #117 |
| `ieee/ieee_warnings` is `ref=hand`: the reference simulator runs numeric_std natively and never prints the body's own warnings (not even with `--ieee-warnings=on`); the second reference simulator and the IEEE source do | LRM policy: the source wins | #94 |
| `std93/`: run at `--std=93` (header `std=1993`): `std_logic_vector` as its own type, 2008 names free (`to_string`, `maximum`, `integer_vector`, `default`), plain shared variables without `relaxed`, the 1995 `numeric_std`, `std_logic_textio`, the Synopsys packages; reference output from sim1 (sim2 agrees on the cases it can run: it needs its synopsys switch for the last two) | Valid 1993 code keeps its 1993 meaning | #629 |
| `shared/`: VHDL-93 style shared variables of non-protected types (header `relaxed`), in packages and in architectures, blocks and generates, also holding access values with heap churn that the shared heap collection must survive (`access_vars`, #303); writers in one cycle only add and every report has its own time, so the output does not depend on process order (#285) | Comparable at any `--threads` and with `--shuffle` | #285 |
| `ignore=order` only with a comment, for same-cycle reports of different processes | LRM leaves the order unspecified | README "Ignore set" |
| `held/`: zero-delay assignments of the value a signal holds, around what must see them (`'active`, `'last_active`, `'transaction`, `'quiet`, deltas, guards, ports, aliases, rejection limits, a postponed process). Each process reads a generic, in an instance of its own, so it has a copy with facts and Cranelift code compares the drive inline (difftest candidate `yavs-clift-check`); the default tiers take no skip on any test of the corpus. `held_record` runs whole record drives around force, release, entries and waveforms of the run, parts, resolved records, delays and ports, long enough for the compare with the record image (`docs/decisions.md` "Record drive compare") on every tier | Skip coverage of the corpus in check mode | `docs/decisions.md` "Drive compare in compiled code" |
| `psl/` uses `ignore=path` (a PSL failure names its directive, not a process); `psl_clock` is `ref=hand` from the second reference simulator, since the first rejects `@` clocks and `assume` | #226 | README "Test header" |

## 3. How to work here

```sh
python3 tools/difftest/difftest.py --bless --filter 'group/name'   # write .expected with the reference simulator (rule 15 wrapping is built in)
python3 tools/difftest/difftest.py --candidate yavs --threads 4 --filter 'group/'
cargo test -p yavs-lower --test corpus
tools/difftest/report.sh                                           # refresh RESULTS.md
```

- A new test: `.vhd` with a header, `.expected` from `--bless` (check the exit status matches
  `exit=`), and, once yavs passes it, its name in `PASS` of `crates/yavs-lower/tests/corpus.rs`.
- Under 5 minutes per test (root rule 16); shrink the scenario, never weaken assertions.
