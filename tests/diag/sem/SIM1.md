## Findings for the sem owner

- `gen/generic_type_no_equality_2008` was dropped: the reference simulator (and the second reference simulator) accept `a = b` on a 2008 `type t` generic, while sem.md Q9 says a 2008 private generic type has no implicit `=`. If Q9 stands, yavs rejects code both references accept.
- The reference simulator `--relaxed` does not relax "pure function reads a signal" (only the impure-call case), so only the call case has an R2 test.
- Several rules are only checked by the reference simulator at elaboration (config binding, division by zero); yavs reports them at analysis by design.
- `E1003` (dependency cycle) cannot be written as a single file that both tools analyze; no test.

## Changes under the LRM interpretation policy (2026-10-18)

what the reference simulators accept. the third reference simulator Starter 2025.3 was used as a third
reference for these files. Every test whose error rested only on an unclear rule was changed:
